# Synera — перевірений пакет, 2026-10-04

**Дороблено п’ять форматів співпраці:** обмін, оплачувана послуга, рекомендація, поєднання форматів і двосторонній пробний проєкт. Усі проходять локальний шлях «умови → дві незалежні згоди → запрошення → прийняття → приватне повідомлення». Current/Atelier і чужа незакомічена правка journey-ui збережені.

**Це кандидат для обмеженого пілота. Весь описаний продукт ще не завершений.** Пуш зберігає код у GitHub; сам по собі не публікує сайт і не створює APK. Production-міграції та новий публічний цикл на момент цього звіту не активовані.

## Що перевірили

- [114/114 регресійних тестів](UNIT_ACCEPTANCE.json), без FAIL/SKIP.
- [П’ять сценаріїв із реальними кліками Chromium 390×844](MODES_BROWSER_ACCEPTANCE.json). Кожен: умови, окремі згоди A/B, запрошення, прийняття, Unicode-текст без виконання HTML. Axe=0, overflow=0, приватне browser storage порожнє. Це транспортні fixtures, не фізичний Android чи справжні акаунти.
- Старий сценарій обміну також пройшов після виправлення регресії: стартовий формат лишився обміном, а компенсація та згода потребують явного вибору. Старий exchangeMaterial не приймає гроші чи відсутність винагороди.
- Локальний PostgreSQL16.15: канонічні SQL/RLS, збереження наявного синтетичного акаунта, відхилення трьох навмисних поломок. Тести кімнат більше не охоплюють усіх користувачів бази.
- [Справжній Neon PostgreSQL18.6](NEON_SQL_ACCEPTANCE.json), приватна гілка `synera-real-journey-check-20261003`: три міграції й три acceptance suite пройшли в одній транзакції. Provider auth.uid() з SQL claims fixtures не підміняли. **HTTP JWT і вхід двох реальних людей цим не перевірено.**
- [Після ROLLBACK](NEON_ROLLBACK_READBACK.png): нових таблиць немає; fixture_users_left=0. Production не змінена. Повний SQL і його hashes збережені в [перевірочному пакеті](NEON_REVIEW_SOURCES.json).
- [Кандидат публікації](RELEASE_CANDIDATE.json): 94 дозволені файли, перевірені bytes/hashes; SQL, тести, fixtures і приватний config не потрапляють до публічного пакета. Закритий Worker зробив 0 зовнішніх викликів.

## Системи: що реально є і що лишилося

| Система | Стан цього пакета / потрібне завершення |
|---|---|
| Презентаційний сайт | Попереднє окреме демо опубліковане; цей пакет ще не опублікований |
| Установлення на телефон | PWA у пакеті; фізичний Android та окремий native APK не прийняті |
| Дизайн, персоналізація, портрети, іконки | Попередні режими й assets збережені; нові форми та чати перевірені в Chromium; художня оцінка людиною окрема |
| Вхід і профіль Give–Take | Наявний Neon Auth/store; локальний шлях перевірений; потрібні дві живі сесії |
| Дозволи й видимість | Приватні RLS і явні згоди перевірені; повна система п’яти режимів довіри не завершена |
| Пошук, взаємний give/need | Регресії заявлених полів пройшли; психологічна «іскра» не доведена |
| Atlas / карта людей | Збережено окреме демо; підстановка ботів у реальний екран не додана |
| Google Maps / місця / маршрути | Працює URL-навігація. Для власних шарів обрано JS + Places + Routes; SDK та живі виклики ще не підключені |
| Місце зустрічі й точна локація | Серверні дозволи/відкликання перевірені SQL; Google ETA і «справедлива дорога» ще не прийняті |
| Переписка | Реальний client/server шлях після прийняття; локальні UI і SQL окремо пройшли; production ще потребує активації |
| AI L, voice onboarding, адаптація голосом | Попередні демо/локальні модулі збережені. Передового живого voice transport у поточному web_launch немає |
| Домовленості, версії, п’ять форматів | Дороблені. Нова редакція вимагає повторних незалежних згод; мовчання не означає «так» |
| Трикутник L / групові кімнати | Мережевий текстовий backend і SQL перевірені; жива багатокористувацька сесія ще не прийнята |
| Голос, відео, переклад, мікрофони | Не завершені; підтвердження брехні чи емоцій «без помилок» не обіцяємо |
| Спільний проєкт / команда | Є двосторонній пробний проєкт із внеском і результатом кожного. Автоматичний набір команди не реалізований |
| Результат зустрічі | Наявний локальний Studio-цикл; незалежного серверного підтвердження виконання ще немає |
| Пам’ять, архів, відновлення | Явний локальний архів збережений; міжпристроєва пам’ять і перевірене відновлення production ще не прийняті |
| Соціальний пакет | Приватні чернетки/експорт; автоматичної публікації не активовано |
| LinkedIn / Instagram OAuth | Не активовані; доступ до «всіх даних» не припускається |
| Радари людей, подій, релізів | Є окремі модулі; живі джерела й фоновий цикл не прийняті |
| Репутація / гейміфікація | Повна система підтверджених внесків не завершена; прокручування не стало досягненням |
| Спільна робота / таймери / добровільні зобов’язання | Не завершені |
| Платні функції / підписка | Paid terms можна погодити; це не checkout. Демо безкоштовне, платежі не активовано |
| Телеметрія / розвиток продукту | Наявність модулів не означає виміряний досвід; потрібні дозволені живі дані й перевірка |
| AI-моделі / кеш / стиснення | Публічна робота ще не прийнята. 10× економія зі збереженням змісту не доведена |

## Шлях і відчуття користувача

Це цілі дизайну, не виміряні емоції чи гормони.

| Крок | Що має відчути людина | Що дає інтерфейс |
|---|---|---|
| Сайт / установка | «Розумію цінність і спосіб входу» | Чітке розділення демо, PWA і реального пілота |
| Профіль / дозволи | «Я контролюю відкриті дані» | Мінімальні поля, явна видимість, окремий доступ до локації |
| Підбір | «Бачу взаємну користь» | Пояснення заявлених give/need, вибір людиною |
| Формат і умови | «Ми домовляємося конкретно» | П’ять форматів; результати, критерії, дати й винагорода кожної сторони |
| Перегляд / погодження | «Мій голос не підмінять» | Поточна редакція, власний checkbox, дві окремі згоди |
| Очікування / запрошення | «Знаю наступний крок і можу відмовитися» | Зрозумілий статус, прийняти/відхилити, без автоматичного «так» |
| Розмова | «Є спокійне місце для дії» | Згорнуті попередні секції, одне поле й одна головна дія |
| Зміна / новий цикл | «Зміни помітні; історію не втрачено» | Нова версія, захист від конкурентного запису, повторна згода |
| Вихід | «Приватне більше не залишається на екрані» | Очищення стану й відкидання запізнілих відповідей |
| Результат / добровільне поширення | «Маю підтверджену користь» | Це ще незавершена серверна частина; чернетка не замінює підтвердження |

## Карта, голос, гроші

[Порівняння актуальних провайдерів і тарифів](PROVIDER_RESEARCH.uk.md): Maps JS/Places/Routes для карти; GPT-Realtime-2.1 для першого голосового тесту, Gemini 3.8 Live для порівняння витрат. Жоден не активований. Історичний Maps credential не повторно використовували. Перед підключенням потрібні обмежені credentials, точний бюджет і приймання реального голосу на Android.

## Ризики й наступний крок

Міграції додають правила доступу та SECURITY DEFINER функції. Реальна SQL-перевірка знизила ризик, але не замінила перевірку підписаного JWT, двох людей, фізичного пристрою й відновлення бази. Відоме попереднє вікно Neon restore — 6 годин; відновлення не виконувалося.

**NEXT, 15 хв:** після точного дозволу застосувати три перевірені міграції до чинного пілота, опублікувати цей кандидат і пройти реальний двосторонній цикл. Maps/voice, checkout, соцмережі та доведене виконання лишаються окремими незавершеними частинами.

Models used: none (provider calls=0, USD=$0.00). Витрати основної підписки цими числами не виміряні.
