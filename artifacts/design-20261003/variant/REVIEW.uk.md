# Atelier 2026 — локальне приймання

**Дата:** 2026-10-03. **Вердикт:** LOCAL_UI_ACCEPTED_WITH_LIMITS. Код стабільний; подальші необов’язкові зміни припинені.

## Інваріант

Новий вигляд вмикається явно. «Чинний» повертає попередні фактичні стилі. Введені поля, незалежні дозволи, активний етап та старий власник `synera.style` збережені. Новий модуль не керує профілем, голосом, публікацією або платежами.

## Два обмежені огляди

1. Прочитано фактичний додатковий diff і чинні реалізації. Нова стилізація ізольована `data-synera-atelier=on`. Знайдений реальний дефект: стара специфічніша рамка disabled-поля не реагувала на «Чіткіші межі». Виправлено тільки рамку в новому шарі; після вимкнення повертається початковий колір.
2. Браузеру віддано `atelier.css` без opt-in правил, без зміни вихідного файлу. Перевірка фактичного rendered style відхилила такий перемикач: `MUTATION_REJECTED.json`. Після цього звичайний сценарій повторно пройшов.

У Studio oracle перевіряє рамку справжнього select, у формі входу — disabled текстового поля. Нативний checkbox без власної рамки не підмінює цей доказ. Вимір стилів не бере приховані налаштування старого меню.
