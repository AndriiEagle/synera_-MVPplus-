**A RECOMMENDED — локальна симуляція, $0.** Однаковий годинний слот дає однакові стани, наступний змінює заняття й умовну демозону Цюриха. Між 21:00 та 08:00 Europe/Zurich персонажі відпочивають. Взаємний запит приймається при переході до наступної години; за браком взаємності бот відхиляє з поясненням. Є ручна кнопка наступної години. Годинні оновлення не перезаписують незбережену форму профілю. Коли вкладка закрита, виконання немає; при поверненні стан рахується за поточним часом.

**B FALLBACK — мовна варіативність через OpenRouter**, worker `deepseek/deepseek-v4-flash-0731`, `effort:low`. На весь світ із 10 персонажів потрібен один серверний batch на годину, не десять запитів і не запит від кожного телефона. Рух і контроль стану залишаються перевірюваними локальними правилами.

## Підготовлений виклик, ще не виконаний

`node tools/bot-hour-pack.mjs` записує `artifacts/bot-hour.plan.json` для **наявного** `C:\Users\Andrii\Desktop\KI\token-monster\swarm.py`. Генератор не читає ключі, не викликає модель і не запускає scheduler. Вхід збирається з allowlist-полів незмінних синтетичних fixtures. Контакт оператора, акаунти, профілі й імпорт користувача не входять до пакета.

- Model: `deepseek/deepseek-v4-flash-0731`; роль worker; reasoning low; один attempt (`retries:1` у канонічному runner), один job, concurrency 1.
- Пакет: до 10 персонажів, 5 демозон, очікуваний JSON. `max_tokens` та `hard_max_tokens`: 8000. Це відповідає наявному мінімуму reasoning runner; не оцінювати витрати лише за видимим текстом.
- Каталог OpenRouter перевірено 2026-09-05: **$0.065 / $0.18 за 1M input/output tokens**, reasoning підтримується. Це ціна каталогу, не обіцянка найнижчої акційної ціни конкретного провайдера. [Модель](https://openrouter.ai/deepseek/deepseek-v4-flash-0731), [публічний каталог](https://openrouter.ai/api/v1/models).
- Консервативна арифметика для 8000 input + 8000 total output: $0.00196/запит, $0.04704/24 запити, $1.4112/30 днів без повторів за цією ціною. Реальна довжина відповіді/ціна провайдера може відрізнятися; це оцінка, не чек і не гарантія місячного рахунку.
- Пропонований перший платний тест: **максимум $0.01 сумарно, 1 API-запит, без повторів**. Періодичний 24-годинний пілот розглядати лише після успішного тесту: окремий максимум $0.10 сумарно, 24 запити, без авто-продовження. Жоден із цих лімітів ще не погоджений.
- Call graph: свіжий synthetic pack → live spend preview канонічного runner → перевірка ledger/spend guard → 1 OpenRouter completion → receipt → `validateBotHour` → людська перевірка корисності → лише тоді підключення до демонстрації.
- Stop: зміна/невідома ціна понад cap, приватні дані, відсутність receipt, обрізана/порожня відповідь, невалідний/прострочений JSON, зайві персонажі/поля, змінений нічний режим. Автоматичного переходу на дорожчу модель немає.
- Expected proof: generation ID, model/provider, prompt/completion/reasoning tokens, actual USD із відповіді, один рядок у канонічному ledger, 10 валідних bot IDs, видимий результат у тестовому режимі. Валідатор JSON сам по собі не доводить оплачений виклик або якість.

## Перед фоновою активацією

Не використовувати браузерний timer для обіцянки цілодобового API. Потрібен погоджений серверний scheduler, захищений server-only ключ, годинний ключ ідемпотентності в сховищі, транзакційне збереження одного snapshot і загальний spend guard. Використати вже наявний Token Monster runner/ledger; не створювати другий router/ledger. Локальний hourly timer цього пілоту не запускає зовнішні API.

План виклику й валідатор готові та перевірені; зв’язок provider snapshot → спільна онлайн-база → усі телефони, scheduler і живий API ще **не реалізовані/не активовані**. Поки що продукт чесно показує локальну симуляцію.
