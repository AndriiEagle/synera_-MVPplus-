# Свій ChatGPT → профіль Synera

У профілі є кнопка **«Заповнити з ChatGPT»**. Вона відкриває короткий шлях: скопіювати завдання → вставити у свій ChatGPT → повернути відповідь → перевірити → застосувати до форми → зберегти профіль.

## Що переноситься

Ім’я, місто, професійна пропозиція та потреба, актуальна ціль, підтверджені навички, мови й умови співпраці. Використовується вже наявний формат `synera-profile-2`; додатковий протокол, база чи модельний роутер не створені. Невідомі факти залишаються порожніми. Давня ціль або доступність не вважається актуальною без підтвердження.

Відповідь розбирається локально у браузері. Системний буфер читається лише після натискання користувача та підтвердження права переносити дані. Якщо браузер не дозволяє читати буфер, є звичайне вставлення в поле. Після вставлення показуються редаговані основні поля й перелік усіх умов. Редагування вихідної відповіді скасовує старе прев’ю. Закриття діалогу очищає текст, прев’ю і підтвердження.

Застосування **замінює поля чернетки**, але не викликає API збереження. Профіль і карта приховані незалежно від імпортованих прапорців. Користувач перевіряє основну форму та окремо зберігає її. Повні архіви, контакти, паролі й стороння історія чатів не потрібні. Synera не відкриває користувацький ChatGPT всередині iframe і не отримує його пароль, сесію або історію.

## Чому API-ключ не переносить пам’ять

Станом на перевірку 2026-09-05 в офіційній документації немає API чи OAuth scope для отримання сторонньою Synera всієї збереженої пам’яті та історії звичайного ChatGPT. API та ChatGPT — окремі продукти. Навіть відповідь власного чату може використовувати лише частину доступного контексту, а не гарантовано всі роки листування.

- [ChatGPT Memory FAQ](https://help.openai.com/en/articles/8590148-memory-faq)
- [ChatGPT та API: окрема оплата й продукти](https://help.openai.com/en/articles/9039756)
- [Експорт ChatGPT](https://help.openai.com/en/articles/9106926): запасний ручний спосіб; підготовка може тривати до семи днів, посилання діє 24 години. Повний архів не є основним шляхом імпорту Synera.

Немає опори на недокументовані `?q=` / `?prompt=` URL. Кнопка відкриває звичайний `https://chatgpt.com/`, без профілю чи історії в адресі. Завдання копіюється окремо. Цей шлях використовує можливості власного ChatGPT користувача; додаткового виклику платного API Synera немає. Ліміти та тариф самого ChatGPT залишаються чинними.

## Наступний офіційний шлях: Synera як застосунок у ChatGPT

Можливе наступне доповнення: OAuth 2.1 для входу саме в **Synera**, MCP-інструмент для перевірки вибраних полів і окремий інструмент їх збереження. ChatGPT передаватиме обмежений професійний профіль за дією користувача. Це не дає Synera права або технічної можливості витягнути повні сирі чати. Потрібні окреме налаштування авторизації, мінімальні scopes, перевірка інструментів та приймання користувачем; зараз цей застосунок не розгорнуто.

- [Apps SDK authentication](https://developers.openai.com/apps-sdk/build/auth/)
- [App guidelines: мінімізація даних](https://developers.openai.com/plugins/app-guidelines/)

## Оркестрація та бюджет цього завдання

Дві окремі задачі Codex працювали паралельно: дослідження офіційних меж і реалізація модуля перенесення. Основний агент інтегрував UI, провів перевірки у браузері; агент модуля окремо перевірив інтеграцію й знайшов залишковий текст/дозвіл після закриття. Виправлення перевірене. Обмін — через повідомлення агентів, спільні файли й наявний план у `artifacts/chatgpt-transfer`, без дублювання роутера або журналу витрат.

Поточне погодження користувача: **до $2 сумарно**. План для `qwen/qwen3.8-flash` та незалежного `z-ai/glm-5.3` містить максимум два виклики, по 8000 output tokens. Публічні актуальні ціни: $0.15/$0.47 та $1.40/$4.40 за мільйон input/output tokens відповідно. Canonical Token Monster preflight оцінив план у $0.005751–$0.042424, але зупинив його до викликів: у канонічному журналі є два попередні записи поточного дня з невідомою вартістю й без generation ID. Ці записи не виправляли й не оголошували безплатними. План **не виконаний**, hosted provider calls = 0, фактичні витрати цього завдання = $0.

Наявність `OPENAI_API_KEY` та `OPENROUTER_API_KEY` перевірена без виводу значень. Наявність OpenAI ключа не доводить eligibility або залишок безплатних токенів. API Data Sharing — окрема програма: потрібні відповідний акаунт, opt-in, дозволені моделі, чинні квоти й баланс. Перевищення може стати платним. Особиста історія й профіль не надсилалися в проєкт Data Sharing.

За перевіреною офіційною сторінкою: групова квота менших моделей — до 10 млн токенів/день для eligible usage tiers 3–5, до 2.5 млн для tiers 1–2; скидання о 00:00 UTC. Запит, який перевищує групову квоту, оплачується повністю. Це не універсальні 10 млн на будь-який ключ чи модель. Факт участі видно в [налаштуваннях організації](https://platform.openai.com/settings/organization/data-controls), використання — у Usage Dashboard за incentive service tier. Поточний акаунт і залишок у цьому завданні не підтверджені.

- [Sharing API inputs and outputs / complimentary tokens](https://help.openai.com/en/articles/10306912-sharing-feedback-and-api-inputs-and-outputs-with-openai)
- [API data controls](https://developers.openai.com/api/docs/guides/your-data)

## Межі приймання

Автоматичні тести та браузерний сценарій використовують явно локальну тестову чернетку, без створення демонстраційного користувача чи запису в production. Мобільна ширина 390 px перевіряє верстку, але не замінює фізичний Android/iPhone. Реальна відповідь із особистого ChatGPT користувача ще потребує його перегляду. Автоматичний серверний AI, повна синхронізація пам’яті та опублікований ChatGPT connector не оголошуються готовими.
