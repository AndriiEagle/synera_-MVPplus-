# Продовження Synera: завершити реальний пілот

> Current route (2026-09-05): Neon Free + Cloudflare Pages. [Live setup state and release instructions](NEON_LAUNCH.uk.md). The Supabase-specific launch steps below are parked.

Працюй у поточному checkout Synera, збережи всі локальні зміни. Прочитай docs/REAL_PILOT.uk.md і актуальний git diff. Не починай нову демоверсію.

Мета: двоє реальних добровільних учасників на Android/iPhone відкривають HTTPS PWA, створюють власні акаунти, підтверджують правила, переносять власні профілі, перевіряють AI-пропозиції, бачать причину взаємної користі, погоджують конкретний час і можуть обмінятися деталями, заблокувати контакт та експортувати/видалити дані.

Уже є: незалежний від Firebase браузерний застосунок, SupabaseStore, profile-brief, profile-package, matching, calendar, map, локальний DOMOVYK adapter, public allowlist та тести. Повторно використай їх.

Закрий фактичні блокери в порядку: HTTP 402 → погоджена SQL-міграція та RLS acceptance → SMTP/повернення з листа → HTTPS → два реальні акаунти → фізичні телефони. Не називай unit tests доказом реальної Auth чи роботи нової SQL. real-pilot.proposal.sql і real-pilot.acceptance.sql ще не виконані. Не застосовуй стару pilot-consent.proposal.sql разом з новою.

AI потрібен для реальних власних профілів. Не називай детермінований matcher AI. Вбудований local endpoint працює лише на комп’ютері й не є публічним AI-сервісом; після ресурсного блокування й одного відхиленого результату генерація зі строгою JSON-схемою пройшла API/браузерну перевірку на одному неперсональному тестовому описі. Це не загальний бенчмарк. Для автоматичного публічного AI спочатку визнач перевірений deployment target та канонічний provider adapter, покажи точний payload/видалення ідентифікаторів, актуальну ціну, max calls і точний cap. Платні виклики, ключі та зовнішні дії лише з відповідною авторизацією. Не створюй другий router/ledger. Альтернатива без Synera API-платежу — власний ChatGPT та перевірена JSON-відповідь у наявному редакторі.

AI може пропонувати, але не публікує профілі, не надсилає запрошення, не вигадує навички й не виступає юридичним арбітром. Не додавай автоматичні рішення щодо людей, платіжні тарифи або «успішність у відсотках».

Перед завершенням: потрібні реальні докази збереження/ізоляції даних, відновлення пароля, прийняття/скасування запрошення, листування, блокування, експорту, видалення та виходу. Якщо зовнішній gate не закритий, збережи перевірені локальні результати, точний блокер і одну наступну дію. Не приховуй блокер за вигаданими учасниками.

Поточні виключення: боти, demo-first, APK, IPA, магазини, платежі, оплачені schedulers, скрейпінг акаунтів, автоматичне надсилання від імені користувача. Оператор правил: Andrii Pokrovskyi, andriipokrovskyi@gmail.com.
