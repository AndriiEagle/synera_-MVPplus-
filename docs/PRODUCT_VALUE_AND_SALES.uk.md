[Сайт Synera](https://synera-summit-20261001.andypokr911.chatgpt.site/) і [Android / iPhone](https://synera-summit-20261001.andypokr911.chatgpt.site/get.html): публічна версія 3, deployment `appgdep_6abfa5e1b9f081919a0039f8997f9e11`, native status `succeeded`, source `925c5ee44938b20d67137d60a1037098defa9e45`.

Додано [окремий локальний режим L](https://synera-summit-20261001.andypokr911.chatgpt.site/triangle.html), схему можливостей і симулятор витрат. Три учасники — нотатки на одному пристрої, не синхронна кімната чи підключений AI. Власник обрав тимчасово безкоштовний Zürich-пілот. Повний новий задум, офіційне дослідження й відкриті серверні роботи: [L_DIRECTION_AND_ECONOMICS.uk.md](L_DIRECTION_AND_ECONOMICS.uk.md).

Головна сторінка пояснює користь, показує інтерактивний приклад підбору → умов → зустрічі. EN / DE / UA, стриманий рух, локальні шрифти, без автоматичної аналітики, фальшивих відгуків чи результатів. «Отримати Synera» веде до інструкцій і наявного [живого пілоту](https://synera-pilot.pages.dev/), а не встановлює презентацію під виглядом продукту. Попередній автономний PWA-продукт зберігається у `web_launch/index.html`; маркетинговий Site має окрему головну сторінку.

## Матеріальні вимоги

| Вимога | Наявна поведінка | Що ще відкрите |
|---|---|---|
| Окремий сайт, який показує цінність | Опублікована презентація та мобільна сторінка отримання | Конверсія й комерційний попит не вимірювалися |
| Android / iPhone | PWA через Chrome / Safari; інструкції працюють також без JavaScript | Фізичні телефони не перевірено; native APK/IPA і магазини не опубліковані |
| Доступ і майбутня оплата | За останнім рішенням власника пілот тимчасово безкоштовний, CHF 0; без картки й автоматичної оплати | Майбутній платний Assistant потребує перевірки попиту, собівартості, затвердженого тарифу/умов і checkout. Наявні CHF39-сценарії не є затвердженою ціною |
| Google Maps | Пошук погодженої адреси, піший маршрут і маршрут до дозволеної точки через Maps URLs | Вбудована Google Maps SDK-карта не реалізована; поточна карта людей — центри міст з добровільним OSM-фоном |
| Пошук людей | Фільтр завантажених дозволених профілів за іменем, містом, заявленими навичками/потребами та метою | Семантичний глобальний пошук не реалізований |
| Підбір / deep match | Двосторонній детермінований підбір за заявленими категоріями, свіжістю й умовами, з поясненнями обох сторін | Глибокий семантичний AI-підбір — відкрита вимога. Поточний score не прогнозує успіх або людську сумісність |
| Узгоджена співпраця | Версії умов, окреме підтвердження кожної людини, зустріч, повідомлення, календар, блокування | Живий сценарій двох реальних акаунтів не прийнятий цими локальними тестами |
| GPS зустрічі | Neon authorisation + KV, явна згода, точність/вікно/відкликання, локальне PG і двосесійне приймання | Новий live rollout ще не виконано; вхід у панелі й точний дозвіл на міграцію залишаються окремими gates |

Не називай увесь продукт фінальним, доки ці матеріальні вимоги не виконано. PWA-продаж може працювати на обох телефонах через веб; він не є доказом публікації в магазинах або native-релізу.
