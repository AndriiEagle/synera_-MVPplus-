# Synera LAB на Android

**Поточний стан 25.10.2026:** [checkpoint і продовження](SYNERA_CONTINUATION_20261025.uk.md). Старий private runtime/Quick Tunnel зараз не підтверджені як робочі; live AI не прийнятий. Результати нижче стосуються датованого кандидата20.10.

Це окремий приватний симулятор 20 вигаданих AI-учасників. Він використовує
чинну модель домовленостей Synera: п’ять режимів, дві незалежні згоди,
передавання тексту, перевірку й прийняття отримувачем. Реальні профілі,
платежі та production SQL не змінюються.

**Статус цього кандидата: локальні перевірки й тимчасове приватне HTTPS
пройдено; живий GLM vision і встановлення на фізичний Android не прийняті.**
Попередній GLM-запит повернув 429 без підтвердженої вартості. Канонічний
Token Monster блокує наступні платні виклики до звірки. Замість AI
заготовлені відповіді не підставляються.

## Запуск

Потрібні Node 22+, Python 3 із Windows launcher `py`, залежності чинного
`package-lock.json`, Chromium і наявний Token Monster. Ключ провайдера
залишається в Token Monster на комп’ютері. Сервер слухає тільки loopback.

```powershell
npm ci
$env:SYNERA_CHROMIUM_EXECUTABLE='C:\Program Files\Google\Chrome\Application\chrome.exe'
node tools/simulation-server.mjs --state=D:\synera-private-state --port=43187 --tm=C:\Users\Andrii\Desktop\KI\token-monster --authority=D:\synera-ai-simulation-20261020\AUTHORITY.json --public-origin=https://YOUR-EXACT-HOST
```

`YOUR-EXACT-HOST` замінюється фактичним приватним HTTPS-hostname.
Локальний authority-файл походить із поточного явного дозволу Андрія,
не з цього документа. Він містить objective `synera-android-simulation-20261020`,
`totalCapUsd: 6` і `modelCapsUsd`: Flash 4, GLM 5.3 1, Argon 1.
Це спільні максимуми всього етапу, включно з попередніми викликами й повторами.
Для іншої задачі цей дозвіл не переноситься.

Без `--tm` і `--authority` можна локально переглянути форму й вручну
підготувати умови; AI позначатиметься як неналаштований.

Приватне посилання з одноразовим для запуску ключем записується в
`<state>/connection.json`. Не публікувати його, каталог state, скріншоти
приватних розмов, provider transport чи ключі в GitHub.
Ключ прибирається з адреси до API-запитів і обмінюється на HttpOnly cookie.
Перезапуск сервера відкликає попередні cookie, але зберігає історію пар.

## Приватне HTTPS без USB

Використовуємо наявний Cloudflare account та іменований Tunnel зі сталим
hostname, спрямованим лише на `http://127.0.0.1:43187`.
Офіційний `cloudflared` запускається як окремий процес, без автоматичного
встановлення Windows service. Доступ до API додатково вимагає приватний ключ
цього запуску. На стороні Cloudflare не кешувати `/api/sim/*`.

Налаштування тунелю, hostname й доступу потребує входу власника.
Тимчасовий Quick Tunnel придатний для короткої перевірки, але зміна його URL
ламає прив’язку встановленої PWA; він не замінює сталу адресу.
Для першого користування вже запущено саме Quick Tunnel: у перевіреному
акаунті немає підключеного домену. Зовнішнє HTTPS, відмова без ключа,
приватний вхід і Secure cookie перевірені. Chromium у звичайному окремому
профілі повернув порожній список installability errors; фізичне
встановлення на Android це не підтверджує.
Офіційні інструкції:
[Tunnel](https://developers.cloudflare.com/tunnel/get-started/),
[downloads](https://developers.cloudflare.com/tunnel/downloads/),
[обмеження Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

Після фактичної перевірки HTTPS відкрий приватне посилання в Chrome на Android,
обери «Встановити» або «На початковий екран». Це встановлювана PWA;
APK не створюється. Для AI комп’ютер, сервер, Tunnel і Token Monster мають
працювати. Офлайн доступна лише публічна оболонка.

## Користування й доказові межі

1. Обери вигаданого учасника, напиши конкретну задачу.
2. Якщо дані справді вигадані, постав згоду на передавання тексту й екранів
   цієї пари провайдеру, натисни «AI-хід».
3. Узгодь умови. Після двох згод виконавець передає текст; отримувач
   перевіряє його за критеріями й окремо приймає або відхиляє.
4. STOP негайно забороняє нові виклики й застосування запізнілої відповіді.
   Уже надісланий провайдеру запит завершує облік витрат; STOP не є
   гарантією безкоштовного скасування.

Кожна автономна дія потребує справжнього PNG 390×844 перед викликом моделі.
Модель отримує лише власну пару й цей екран; натискання/введення виконуються
через той самий UI. Журнал зберігає hashes, рішення, receipt, revision
і знімок після дії. Невидима кнопка, інша редакція чи STOP відхиляють дію.
Фізичний телефон не імітується в доказах: це мобільний viewport Chromium.
Один хід обмежено 12 рішеннями; нескінченного фонового циклу немає.

Живе зображення підтримує перевірений catalog ID `z-ai/glm-5.3-flash`.
`z-ai/glm-5.3` у перевіреному каталозі текстовий; його не видаємо за vision.
Історичні Laya/Jev — текстові дорадчі адаптери; вони не прийняті як
контролери цієї програми. 20 ролей не є 20 реальними клієнтами.

Симуляція може дати корисну чернетку, перевірити зрозумілість інтерфейсу
та знайти технічні збої. Вона не доводить попит, оплату чи повернення людей.

## Відтворення локальної перевірки

```powershell
node --test web_launch/simulation-session.test.mjs tools/simulation-server.test.mjs tools/simulation-runner.test.mjs
py -3 -B -m unittest discover -s tools -p test_simulation_provider.py
node tools/simulation-browser-acceptance.mjs
```

Browser acceptance використовує справжні HTTP, cookie, UI й PNG, але
**синтетичного контролера та ін’єкцію відповіді моделі**. Це окремо від
непройденого живого GLM vision. Тест не витрачає гроші.
