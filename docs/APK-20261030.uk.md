## K3 — відтворення й передача власнику сайту

```powershell

```

Команда заповнює копію `android/twa-manifest.json` у приватному `twa/`, виконує
`bubblewrap update --skipVersionUpgrade` і `bubblewrap build --skipPwaValidation`,
перевіряє APK через `apksigner` і `aapt`, звіряє сертифікат із keystore, перевіряє AAB.
Вхідний шаблон з placeholders не змінюється. Команди не очікують вводу; логи очищуються
від паролів до запису. Дочірній процес успадковує лише потрібні системні змінні,
без provider API keys/tokens. Жодних installer/deploy викликів у release-tool немає;
перший Gradle build може докачати SDK/build dependencies у вказані приватні каталоги.

У заданий вихідний каталог потрапляють тільки:

- `synera.apk`;
- `synera.apk.sha256`;
- `.well-known/assetlinks.json` із реальним сертифікатом;
- `android-release.json` із package/version/size/hash та `published:false`.

AAB залишається в `C:/Users/Andrii/.synera-android/twa/app-release-bundle.aab`.
APK оригінал — `twa/app-release-signed.apk`. Бінарні файли до Git не додаються.
Спочатку збирати вебпакет, потім додавати Android-файли: наявний вебbuilder
навмисно відхиляє неочікувані файли при повторній збірці каталогу.

Claude має скопіювати **вміст** `tmp/apk-release/`, включно з прихованим `.well-known`,
у готовий Vercel preview-каталог. Локальний `web_launch/server.mjs` не є сервером цієї
видачі; його PUBLIC_ASSETS і SW не змінені. APK не додається до offline cache.
Vercel статично обслуговує додані файли без зміни app server. Це ще треба підтвердити
реальними HTTP-запитами після окремого deployment власником.

## K5 — точний фрагмент для get-лінії

`get.html` ця лінія не редагувала. Розмітка для власника:

```html
<a id="apk-download" href="/synera.apk" download hidden></a>
<small id="apk-sha256" hidden></small>
```

Код додати до **наявного зовнішнього JS-модуля** сторінки, а не inline script
(чинний CSP не дозволяє inline JS). Підписи бажано включити до її наявного i18n:

```js
async function showApkDownload() {
  const button = document.getElementById('apk-download');
  const hash = document.getElementById('apk-sha256');
  button.hidden = hash.hidden = true;
  try {
    const response = await fetch('/synera.apk', {
      method: 'HEAD', cache: 'no-store', redirect: 'error'
    });
    if (response.status !== 200) return;
    const metadata = await fetch('/android-release.json', { cache: 'no-store', redirect: 'error' });
    if (metadata.status !== 200) return;
    const release = await metadata.json();
    if (release.packageId !== 'ch.synera.app' || !/^[a-f0-9]{64}$/.test(release.sha256)) return;
    const lang = document.documentElement.lang.split('-')[0];
    button.textContent = { uk: 'Завантажити APK', de: 'APK herunterladen', en: 'Download APK' }[lang] || 'Download APK';
    hash.textContent = `SHA-256: ${release.sha256}`;
    button.hidden = hash.hidden = false;
  } catch { /* APK unavailable: keep the download hidden. */ }
}
showApkDownload();
// Call again from the existing language-change handler.
```

Перед прийманням get-лінії: `HEAD 404/500/network failure` → кнопка й хеш приховані;
`HEAD 200 + valid metadata` → кнопка та **повний** SHA-256 видимі; click завантажує APK;
укр./нім./англ. підписи змінюються разом із мовою. Хеш файла і хеш сертифіката різні.
