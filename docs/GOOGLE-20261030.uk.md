## Поведінка

- **W1.** За готового Neon, `registrationEnabled=true`, `googleOauthReady=true`
  та чинного `googleOAuthEnabled=true` перший екран містить одну головну дію
  «Продовжити з Google» і малу «або код на пошту». Email/OTP згорнуто.
  Hero/Demo/інші великі дії приховано лише в цьому стані. Темна кнопка:
  кольоровий G, `#131314` / `#8e918f` / `#e3e3e3`, локальний Google Sans Medium,
  клавіатурний фокус. Орієнтир — [Google branding](https://developers.google.com/identity/branding-guidelines).
- GET `/api/neon/oauth/google/start` запускає тільки ідентифікацію. Він зберігає
  чинний challenge/verifier bridge Neon; не вигадує application consent.
  Попередній consent-bearing POST залишається сумісним. Cross-site start
  відхиляється, callback має чинні перевірки. Після callback користувач отримує
  приватну редаговану чернетку. Ім'я береться з bounded provider `name`, ніколи
  не з email; рядки з `@`, control chars або понад 60 символів не підставляються.
  Власне збережене ім'я має пріоритет над ім'ям Google.
- У чернетці немає автоматичного запису профілю, публікації чи згоди. Для
  продовження/збереження відкривається окремий наявний notice із двома порожніми
  прапорцями. Після явного підтвердження записується лише policy consent;
  відредаговані поля лишаються, видимість і карта вимкнені. Збереження профілю
  лишається окремою кнопкою. Інші розділи до policy заблоковані в UI; серверні
  admission/RLS не змінювалися і залишаються окремим release gate.
- **W2.** Чинна HttpOnly session відновлюється на відкритті без натискань.
  «Вийти» є в меню шапки; під входом — підказка для спільного пристрою.
- **W3.** Google відмовлено/скасовано → чистий URL, повідомлення та розгорнутий
  email-шлях. У preview без backend — локальна чернетка + Demo, без Google CTA.
  uk/de/en використовують чинну таблицю локалізації; особисті поля не перекладаються.
- **W4.** [10-хвилинний runbook](GOOGLE-ONE-TAP-20261030.uk.md),
  `tools/google-signin-smoke.mjs` + тест. Smoke звіряє public gates, точний
  очікуваний client ID і два redirect hops через дозволений Neon до Google;
  не запитує Google login page і не авторизує користувача. Public client ID
  читається з `SYNERA_GOOGLE_CLIENT_ID`; secret лишається лише в Neon.
  Env-mapping deploy kit доповнено; весь комплект не згенеровано/не опубліковано.
