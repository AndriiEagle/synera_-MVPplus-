## Межа готовності та наступний реліз

Це перевірений локальний демонстраційний пакет, не повністю запущений продукт. Стан публікації зберігається в окремому поточному результаті; успішна збірка не є деплоєм.

1. Для показу на фізичному Android: окремий HTTPS preview, відкрити Chrome, перевірити всі три кроки, Google Maps, перше завантаження → airplane mode → повторне відкриття. Емуляція Chromium не підтверджує конкретний телефон.
2. Для реального пілоту: підтвердити цільове середовище й міграцію case-state, робочий вхід та збереження; пройти двома окремими акаунтами погодження/редагування/відкликання/зустріч. Старі прапорці readiness не є актуальним runtime-доказом.
3. Для живого GPS між телефонами: authenticated recipient transport, політики доступу, припинення/видалення, відмова у дозволі, фоновий/застарілий сигнал, два фізичні телефони. Поточні локальні grants цього не реалізують.
4. Для production і платежів: закрити правові/операційні рішення з `BLOCKED_HUMAN.md`, перевіривши їх актуальність. Нативний APK не збирався.

Точну дату повноцінного production не підтверджено: потрібні результати цих перевірок і зовнішні рішення. Дедлайн 20:00 стосується демонстрації, не гарантії завершення всіх production-функцій.
