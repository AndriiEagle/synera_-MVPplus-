## Що має забрати інтегратор

У цій базі немає `privacy.html` і `pilot-consent.html`. Публічна Simulation з agents lane приховує старий LAB і створює власний root через `simulation-living-ui.mjs`; звичайна HTML-вставка лишилась би в прихованому LAB. Pilot consent створює h1 динамічно й перестворює його при зміні мови. Через заборону змінювати чужі скрипти ці шви підготовлено **в patch**, не застосовано до продукту цієї гілки.

[pending-integration.patch](graphics2-20261029/pending-integration.patch) містить тільки:

1. Privacy: один figure після h1 і один stylesheet.
2. Pilot consent: один stylesheet; renderer додає один legal figure після свого h1 при кожному locale render.
3. Public Simulation renderer переносить уже наявний static figure після `#living-status`, зберігаючи рівно один figure для public/LAB режимів.

Patch перевірено `git apply --check` на копії точних owning-lane inputs. Усі чотири input hashes збіглися зі свіжими файлами на фінальній перевірці; patch **не застосований**. [Patch check](graphics2-20261029/patch-check.json). Preview брав тільки публічні allowlisted assets з `C:/sw/synera-adaptive`, підставляв зміну через тимчасову browser route і не писав у ту теку. Усі шість page/device сценаріїв пройшли, primary action видимий; у Pilot consent зберігається один figure після uk/en/de і він прихований для друку. [Точні input hashes і геометрія](graphics2-20261029/pending-integration-evidence.json).

Кадри `*-staged-*` — перевірений read-only preview, **не merged/runtime acceptance**. Звичайні `*-simulation.html-*` у цій базі показують старий світлий приватний LAB з відсутнім endpoint; це не прийнята публічна demo-сторінка. Сцену для нової темної публічної сторінки показують лише `*-simulation.html-staged-*`.

Після злиття owner звіряє patch із чинним renderer-ом, робить `git apply --check` / застосування, потім запускає:
