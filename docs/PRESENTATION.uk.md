# Synera: презентація на 3 хвилини

**Можна показати працюючу демонстрацію з вигаданими людьми. Онлайн-пілот поки не відкритий: Supabase повертає HTTP 402.** Карта, голос та AI не входять до цього показу. Додано імпорт власного профілю, картку для ручного поширення і короткі локальні підказки взаємної теми.

Для бізнес-зустрічі з Гілбертом підготовлено окремий [пакет із дослідженням, ціною, промптами та пілотом](meeting-gilbert/README.uk.md). Додаткова сторінка `/lab.html` показує порівняння бізнес-профілів за явними правилами та економіку підписки. Це локальний прототип без LLM, не демонстрація працюючого AGI.

## Одне речення

Synera допомагає знайти людину, з якою твої інтереси, потреби та вміння можуть стати взаємною користю.

Приклад: Олена хоче практикувати мову й уміє фотографувати; Марко шукає фотографа й готовий допомогти з мовою. Їм потрібен простий спосіб побачити спільний інтерес і запропонувати зустріч. Імена й ситуація вигадані.

## Що показати

Запуск: `node web_launch/server.mjs --demo`. Відкрити адресу, надруковану в терміналі.

| Час | Дія |
| --- | --- |
| 0:00–0:30 | Пояснити проблему та приклад взаємної користі |
| 0:30–1:00 | Натиснути «Спробувати демо», відкрити «Мій профіль», показати прогрес профілю, імпорт і картку |
| 1:00–1:40 | «Знайти людей» → учасник Б → показати підказку взаємної теми → «Запропонувати зустріч» |
| 1:40–2:10 | Перемкнути демо-учасника на В: чужого запиту немає |
| 2:10–2:40 | Перемкнути на Б → «Зустрічі» → «Прийняти»; повернутися до А й показати відповідь |
| 2:40–3:00 | Пояснити поточний статус і запитати, чи зрозуміло, навіщо тут знайомитися |

Сценарій синтетичної демонстрації пройшов браузерну перевірку. Перезавантаження скидає її дані. Не вводити реальні контакти, приватні щоденники чи особисті повідомлення в цей показ.

## Що можна стверджувати

| Твердження | Статус |
| --- | --- |
| Профіль, список людей і запит на зустріч працюють у демо | Перевірено в браузері |
| У новій базі застосовано захист профілів і зустрічей | Перевірено SQL-тестами та advisors |
| Імпорт/експорт профілю і картка поширення | Перевірено локальними unit-тестами; реальний mobile share треба перевірити на HTTPS |
| Можна зареєструватися й працювати онлайн | Ще не прийнято: квота й доставка email |
| Є робочі карта, голос, AI-добір і мобільна збірка | Лише старий Flutter-код; до цього показу не входять |
| Відновлено старі Firebase-дані | Ні; експорт недоступний |

## Три запитання після показу

1. Кого ти хотів би знайти тут і для якої конкретної справи?
2. Чи зрозуміло, як надіслати запит і хто його бачить?
3. Які поля профілю ти готовий зробити видимими іншим?

Наступна продуктова перевірка: після відновлення сервісу два незалежні тестери мають пройти справжній вхід → профіль → запрошення → прийняття → повторний вхід. До того демонстрація показує сценарій продукту, а не результати реальних користувачів.
