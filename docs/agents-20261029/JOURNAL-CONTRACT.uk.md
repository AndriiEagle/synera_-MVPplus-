# Локальний журнал — контракт для privacy lane

Єдиний ключ даних цієї лінії: **`synera.journal.v1`**, `localStorage`, JSON-масив.
Інших ключів профілю, повідомлень або seed ця лінія не створює.
Наявні глобальні ключі вибору мови/оформлення не змінено.

```json
[
  {
    "at": "2026-10-29T20:00:00.000Z",
    "kind": "profile",
    "actor": "visitor",
    "text": "Локальну чернетку профілю збережено",
    "data": {
      "source": "profile",
      "profile": {"name": "Alex", "offers": "Дизайн", "seeks": "Дослідження"}
    }
  }
]
```

- Код сховища: `web_launch/journal.mjs`, експорт `JOURNAL_KEY`, `createJournal(storage, now)`.
- Кожна подія має рівно оболонку `{at, kind, actor, text, data}`. `at` — фактичний ISO timestamp запису,
  а не сценарний час зустрічі. `data` — об’єкт; доповнення мають лишатися всередині нього.
- `data.source`: `profile` (явно збережена картка), `visitor` (власна Demo-співпраця),
  `community` (розмови вигаданих людей та seed сеансу).
- `kind`: `session`, `profile`, `consent`, `proposal`, `question`, `change`, `message`,
  `confirmation`, `meeting`, `result`. Відмова — `message` із завершеним станом `declined`.
- `actor`: `visitor`, `bot-<key>` або `Demo` для початку сеансу. Жодного запису в Auth/реальні таблиці.
- Події відвідувача містять `data.version` і `data.state` — локальний стан розмови, щоб reload не втрачав
  погоджені умови/окремі згоди. Це синтетичний стан із текстом введеної картки; він також підлягає стиранню/expiry.
- Профіль головної сторінки не починає зберігатися від самого введення. Явна кнопка
  «Зберегти чернетку в локальний журнал» записує три поля; перехід у симуляцію також передає відкриту
  чернетку локально. Незаповнені поля можна доповнити у 3-польовій картці. Жодних контактів або прихованих полів.
- `entries(source)`, `export(source)`, `erase()`, `profile()` — публічні методи. Експорт містить
  `{format, exportedAt, entries}`; фільтр однаковий для екрана, JSON і друку.
- `erase()` видаляє ключ. У поточній симуляції він також скидає картку, скасовує очікувану відповідь та
  зупиняє автопрогравання. Видалення з іншої вкладки обробляється через `storage`; таймер додатково
  перевіряє наявність ключа перед записом, щоб запізніла відповідь не відновила стерте.
- Пошкоджений оригінал не перезаписується. Недоступне сховище залишає нові події в оперативній пам’яті
  з видимим попередженням; можна експортувати JSON. Стирання не оголошується успішним, якщо browser його заборонив.
- **30-денний expiry та перелік у privacy centre належать privacy lane**. Тут expiry не реалізовано,
  щоб не дублювати її власника. Privacy lane має очищати записи за `at`, а не створювати другий ключ/копію журналу.
- Сховище локальне для origin/browser/device. Копія JSON після завантаження вже керується користувачем;
  автоматичного хмарного backup або обміну між пристроями немає.
