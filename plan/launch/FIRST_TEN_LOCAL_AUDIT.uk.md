# Synera: два локальні проходи першого користувача

Дата: 2026-09-23. Порівняно web UI бази `e39e5c0` і локальної збірної гілки `codex/synera-first-ten-integration` через один і той самий demo-сервер і Chromium, desktop 1280×800 та mobile 375×700. Машинний журнал: `artifacts/first-ten-audit/journey.json`; 20 PNG у папках `before-e39/` (9) і `after-integration/` (11). Це локальні файли, не деплой.

Після першого візуального огляду знайдено дефект: Atelier надавав неактивній кнопці входу темне тло з тьмяним текстом. Новий computed-style E2E спершу впав, CSS виправлено, повторний огляд PNG підтвердив світлу disabled-поверхню. Після зведення `node --test`: 419 pass, 1 skipped; `npx playwright test`: 13/13 pass. Аудит доступності минулої CI-хвилі має окремий локальний gate; ці кадри не доводять відповідність живого сайту.

**Залишаються ворота запуску:** remote CI-патч ще не запушений; live UI старіший; legal-чернетка потребує кваліфікованого review та синхронного policy-version/hash; живий backend і міграція не прийняті; перша ціна, платник, реквізити та договір із Гілбертом не підтверджені; локальний QR-bill генератор заблокований через дефект формату SIX. Для першого платежу потрібен ручний рахунок від реального payee і звірена оплата.
